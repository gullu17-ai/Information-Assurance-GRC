The verified assignment source extracts are in sources/A1.txt through sources/A4.txt. They correspond to the four user-supplied assignments, including the independent third-party PASS audit. Original attachments remain the authoritative layouts; extracted text can omit image-only panels. A3 supplies IAM, classifications, recovery and incident response. A4 supplies independent findings F-01 to F-13, tests T-01 to T-04 and a 44.46/100 weighted documentary score.
